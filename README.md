# ⚔️ 漢字の勇者ケイト

あそんでいたら、いつのまにか漢字をおぼえている！ スマホで遊べる 4択クイズRPG です。

- インストール・登録・ログイン・セーブは **なし**（ブラウザを閉じたら最初から）
- スマホの縦画面がメイン。PCのブラウザでも遊べます
- サーバーの処理はいらない「静的サイト」なので、GitHub Pages などにそのまま置けます

---

## 起動方法

### PCで遊ぶ
1. `start.bat` をダブルクリック
2. ブラウザが自動で開きます（開かないときは `http://localhost:8080/` を開く）
3. 終わるときは黒い画面（サーバー）を閉じる

> `index.html` を直接ダブルクリックすると、ブラウザの制限で問題データを読みこめません。かならず `start.bat` から開いてください。
> `start.bat` は Node.js（なければ Python）を使います。

### 同じWi-Fiのスマホで遊ぶ
`start.bat` の黒い画面に出る「スマホ用」の URL（`http://192.168.x.x:8080/` など）をスマホのブラウザで開きます。
Windows のファイアウォールの確認が出たら「プライベートネットワーク」を許可してください。

### URLを送るだけで遊べるようにする（公開）
フォルダの中身をそのまま静的ホスティングに置くだけです。`tools/` フォルダは公開しなくてもかまいません。
例：GitHub Pages なら、リポジトリにこのフォルダの中身を置いて「Settings → Pages」で公開 → 出てきた URL を送るだけ。

## ゲームの流れ

```
タイトル → 主人公（ケイト／ユウリ）→「◯◯は何年生？」→ 王さまの お話
→ 冒険 1〜40問（10問ごとにエリアが変わる・エリアボスあり）
   ├ 40問ぜんぶ正解 → 魔王城（41〜50問・ボス戦）→ TRUE END（50問全問正解）/ BRAVE END
   └ とちゅうで まちがえた → 1〜2問あとに特別ダンジョン（10問）→ 中ボス撃破 → HAPPY END
        1〜13問目でミス：ゴブリンどうくつ（ゴブリンキング）
        14〜27問目でミス：のろいの森（ダークウルフ）
        28〜40問目でミス：古代いせき（古代の守護者）
→ リザルト（スクショ用の1画面）
```

- まちがえても ゲームオーバーにはなりません。正解が足りなくても、仲間の力でかならずボスをたおせます。
- 武器・仲間・属性・コンボは **演出だけ** です。問題のむずかしさや正解には影響しません。
- 選択肢は毎回シャッフルされ、正解の位置は毎回かわります。

## 問題について

- 問題数：**4,127問**（学年別：1年 374／2年 450／3年 536／4年 842／5年 905／6年 1,020）
- 問題の種類：よみ・かき・あなうめ・つかう ことば・まちがいさがし・いみ・おくりがな・文の中のよみ／かき・にた かんじ・くみあわせ（部首・四字熟語）・つかいかた
- **学年のきまり**：問題文・選択肢・解説に出てくる漢字をすべて「学年別漢字配当表（2020年度〜の学習指導要領、1026字）」と照らし合わせ、
  いちばん上の学年を その問題の学年にしています。ゲームは「えらんだ学年以下」の問題しか出しません。
  （例：4年生を選ぶと、5・6年生の漢字が1字でも画面に出る問題は出ません）
- 後半ほど、えらんだ学年の漢字が多くなります。魔王城の10問は、えらんだ学年の漢字が中心です。
- 教育漢字（1026字）以外の漢字は、データを作るときにエラーにして入らないようにしています。

## 問題の追加・修正

問題のもとは `data/source/g1.txt`〜`g6.txt`（ふつうのテキスト）です。直したら、次のコマンドで `data/questions/` を作りなおします。

```
node tools/build_questions.mjs
```

書き方（1行に1つ。`|` で区切る）：

| 種類 | 書き方 | 例 |
|---|---|---|
| ことば | `W|ことば|よみ(/べつの読み)|いみ|まちがった書き方,…|まちがった読み,…` | `W|先生|せんせい|べんきょうを おしえて くれる 人|先正,千生,天生` |
| 文 | `S|［ ］で かこんだ 文|よみ|まちがった書き方,…|まちがった読み,…` | `S|［雨］が ふって きた。|あめ|両,天,水` |
| おくりがな | `O|正しい形|よみ|まちがい,…|いみ` | `O|新しい|あたらしい|新い,新らしい,新たらしい|できた ばかり` |
| 自由問題 | `Q|タイプ|大きく出す字|問題文|正解|まちがい,…|解説|むずかしさ1-3` | `Q|combine|木＋木|「木」が 二つで できる かんじは？|林|森,竹,本|…|1` |

- `W` の1行から「よみ・かき・あなうめ・つかう ことば・まちがいさがし・いみ」の問題が自動でできます。
- 「まちがった書き方」が本当にある別の言葉（例：右手 に対する 左手）のときは、`data/source/real_words.txt` に書いておくと「まちがいさがし」の答えに使われません。
- 作るときに、配当表にない漢字・まちがい候補の不足などをチェックして表示します。

## フォルダ構成

```
index.html            画面（1ページの中で切りかわる）
css/style.css         見た目・アニメーション（スマホ縦画面が基本）
js/main.js            ゲームの流れ・バトル・分岐・エンディング・リザルト
js/quiz.js            問題の読みこみ・出題えらび・選択肢シャッフル
js/fx.js              演出（パーティクル・カットイン・ガチャ など）
js/audio.js           効果音・BGM（WebAudio で生成。音声ファイルなし）
data/game.json        キャラ・モンスター・ルート・ごほうび・セリフの設定
data/kanji_grades.json 学年別漢字配当表
data/source/          問題のもと（ここを編集する）
data/questions/       ゲームが読む問題データ（自動生成）
assets/img/           画像（WebP。全部で約2.4MB）
tools/                開発用（問題ビルド・ローカルサーバー・画像生成）
start.bat             PCで遊ぶときの起動用
```

## 画像について

キャラクター・モンスター・背景・武器は、ローカルの画像生成AI（Animagine XL 4.0）で作り、背景をぬいて WebP にしています。
作りなおすときは `tools/gen_images.py`（生成）→ `tools/process_images.py`（背景ぬき・縮小）。
原画 `tools/ai_raw/`（約60MB）は公開には不要です（`.gitignore` 済み）。

## 音について

最初の「ゲームスタート」をタップしたあとから音が出ます（スマホの自動再生制限のため）。
右上の 🔊 ボタンでいつでも ON/OFF できます。音が出なくても最後まで遊べます。
